# J&W Foods growth proposal (Minastech, October 2026)

A static website in the style of the Oliver Cole and Blü River proposals: 7 clickable prototypes, the AI agents that 10x the desk, the business case, the $1M plan, the research and the full proposal.

## What is where
| Path | What |
|---|---|
| `site/index.html` | Hub: recommendation, 7 prototype cards with screenshots, competitors, AI and $1M teasers, shortlist email |
| `site/prototypes/01…07-*.html` | The 7 prototypes (customer view + "JW team" view, demo checkout on JW's real routes, AI chat, "Why this makes money") |
| `site/agents.html` | 16 AI agents, the 10x levers, rollout, guardrails, cost |
| `site/roi.html` | Business case with a calculator |
| `site/million.html` | 11 ideas scored out of 100, the recommended $1M path, a "build your own path" picker |
| `site/research.html` | Audit, the 7 competitors, everyone we checked, benchmarks, AI evidence, the full research reports |
| `site/proposal.html` | The written proposal (Save as PDF from the browser) |
| `site/assets/site-data.js` | All numbers and copy (generated by `tools/build_data.py`; text fixes in `research/data-fixes.json`) |
| `site/assets/catalog.js` | 111 real JW products (generated by `tools/build_catalog.py` from jwfoods.com/products.json) |
| `site/assets/concept.js/.css` | Shared prototype chrome |
| `research/` | All research, play designs, CFO review, final review and workflow outputs |
| `dist/`, `JWFoods-proposal.zip` | Deploy-ready copy (built by `tools/package.sh`) |

## To confirm before sending
- **Minastech fee**: set to $3,500/month + $6,000 setup (6-month first term, day-90 KPI review). This was a placeholder from the strategy pass; change it in `research/data-fixes.json` or `tools/build_data.py` and rebuild.
- **People**: owners are addressed as "Bill, Stavros". Other family members are referred to by role only.
- **"No added salt, sugar or oil"**: JW markets the Meal Butler line this way, but a few JW ingredient lists include salt, oil or sugar. The site words it carefully; worth raising with JW.

## Run, rebuild, check, deploy
```
python3 -m http.server 8787 --directory site      # preview at http://localhost:8787
python3 tools/build_catalog.py && python3 tools/build_data.py && python3 tools/build_docs.py
tools/check.sh prototypes/01-goal-plan-builder.html # JS errors + layout/a11y at 390 and 1280
tools/check-page.sh index.html
tools/shoot.sh                                       # hub thumbnails
tools/package.sh                                     # dist/ + JWFoods-proposal.zip
```
Deploy: drag `dist/` (or the zip) onto Netlify Drop, or `npx netlify-cli deploy --dir dist --prod` after `netlify login`. Pages carry `noindex` and `dist/robots.txt` blocks crawlers.
